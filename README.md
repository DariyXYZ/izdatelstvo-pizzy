# Издательство пиццы

Сайт-визитка пиццерии. Сейчас — статические превью для согласования:

- `index.html` — ч/б скелет сайта. Структура как у DFF (Главная без скролла → О нас / Меню / Забронировать), типографика как у A-Index (белый фон, Times condensed + узкий гротеск). Главная — рисунок фасада (SVG-заглушка) + инфострока.
- `refs/` — фото места (вход с лестницей, дерево с гирляндой, столик с лимонами).
- `fonts.html` — подборка шрифтов с кириллицей.
